> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the plan declare time zero and eligibility timing, make the lock take a variable dictionary and refuse or flag timing problems, and show every flag with its response in a new identification table in the dossier and the Muntner log.

**Architecture:** Two new `analysis_plan()` arguments (`time_zero`, `eligibility`) and one new `create_analysis_lock()` argument (`dictionary`). Dictionary validation lives in a new file `R/dictionary.R` (one checker, called by the lock). The identification table is built from the lock by `.identification_table(lock)` in a new file `R/identification.R`, stored in the dossier, rendered by the template and turned into Muntner rows. No new exports.

**Tech Stack:** R 4.4.2, testthat 3, roxygen2, devtools, Quarto (dossier render).

**Spec:** `docs/superpowers/specs/2026-10-18-cleantmle-0.5.0-p1-time-zero-design.md` (approved by Andrew 2026-10-18). Read it before each task.

## Review Focus

1. **Whitespace-only responses.** A `reason`, `sensitivity` or `response` of `"  "` must count as missing. Test in Tasks 1 and 2.
2. **Dummies of one variable disagreeing.** Rows sharing `variable` but differing on `recorded`, `fixed`, `follow_up` or `role` must be an error naming the variable. Otherwise `payment_selfpay` declared `after` and `payment_insurance` declared `before` would split one variable. Test in Task 2.
3. **Dictionary types.**
   - A tibble, factor columns, or `follow_up` as the strings `"TRUE"`/`"FALSE"` must give the same lock and hash as a plain data frame with logical `follow_up`.
   - `NA` in any required field is an error naming the field.

   Test in Task 2.
4. **A column that is both a restriction variable and a covariate.** It takes its covariate role, and the lock accepts it. Test in Task 2.
5. **A 0.4.x lock reaching any verb.** It must give the re-lock message, never a hash mismatch or a crash on a NULL dictionary. Test in Task 3.
